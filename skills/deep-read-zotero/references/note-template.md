## 写作检查清单（交稿前自检）

- [ ] 总长 6000-10000 字符
- [ ] 5 问清单每项有 `[OK]`/`[注意]`/`[红旗]` 标记 + 具体证据
- [ ] 至少 1 个 `[注意]`（找不到说明批判不够深）
- [ ] 核心发现表格有具体数值（不止"显著升高"）
- [ ] 精翻部分 ≥ 摘要 + 引言 + 方法 + 结果 4 节
- [ ] "给我的启发"里有 ≥3 个具体空白点
- [ ] 术语表 ≥10 条
- [ ] 文件名符合 `{ITEMKEY}_xxx_v2.0.html` 规范
