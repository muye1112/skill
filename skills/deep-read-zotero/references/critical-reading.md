# 批判性阅读方法论（5 问法）

> 来源：Sartorius N, Thornicroft G. (2025). How to read a research paper. *Clinics in Integrated Care*, 28, 100247.
> 作者是 WHO 精神卫生司前主任 + King's College London 精神病学教授。

## 核心理念：从"接受式精读"到"批判性精读"

| | 接受式（v1） | 批判性（v2.0） |
|---|---|---|
| 核心问题 | "作者说了什么？" | "**作者为什么这样说？可信吗？与别人一致吗？**" |
| 笔记产出 | 全文翻译 + 摘要 | 翻译 + **5 问批判清单** |
| 对课题的价值 | 了解领域 | **找到空白、发现弱点、识别红旗** |

## 3 层漏斗决策树（先决定要不要精读）

```
标题 → 你懂吗？感兴趣吗？ ──否──→ 丢掉
  │是
摘要 → 与研究高度相关？ ──否──→ 记一句话笔记走人
  │是
全文 → 进入 5 问批判阅读
```

## 5 问批判清单详解

### 问 1：作者与利益（Who and why）

- 作者团队背景与本文方向是否匹配？（做砷神经毒性的是否长期深耕此方向）
- **资助来源**：国家自然科学基金？商业公司？（后者警惕）
- **利益冲突（COI）声明**：有没有？缺了是硬伤
- 作者贡献是否符合 ICMJE 标准（构思/设计/执行/分析/撰写/批准）
- **谁可能从结果中受益？**（如发现"FTO 激活剂保护神经元" → 药企利益）

### 问 2：背景与目的（Why this question）

- 引言是否公平引用前人？**有没有回避与自己假说矛盾的证据？**
- 研究目的是否以**可回答的"问题"形式**陈述？（"探索…"式模糊表述 = 弱）
- 空白是真的空白，还是别人做过只是没被引用？

### 问 3：方法学可信度（How，最关键）

- **样本量计算**：报告了吗？没报告是红旗 🚩
- **随机化 / 盲法**：实施了？谁被盲？（行为学测试尤其关键）
- **对照组**：与实验组匹配吗（年龄/性别/窝别）？
- **伦理批准号**：必须报告。缺失 = 硬伤
- **统计方法**：多重比较校正？预先注册？
- **可复现性**：仅凭方法部分能否复现实验？

### 问 4：结果可信度（What was found）

- 结果是否**直接回答了引言末尾的研究目的**？（逐条对照）
- 效应大小 + 95% CI 是否报告（只有 p 值不够）
- 图表统计标注完整性（n、p、误差棒含义）
- 关键实验的 biological replicate 次数
- **颠覆性结论** → 数据能否经得起 5-10 倍样本量复现？

### 问 5：讨论与定位（So what）

- 讨论是否简洁/平衡/公平？（长篇大论常在掩饰问题）
- **局限性是否充分承认？**作者说"无显著局限性" = 红旗 🚩
- 与前人一致还是矛盾？矛盾处有没有解释？
- 结论是否被数据过度解读？（"hypothesis-generating" vs "definitive"）

## 标记体系

每个维度给三档标记：

| 标记 | 含义 |
|---|---|
| `[OK]` | 做到位，有证据 |
| `[注意]` | 有缺失或可质疑，列出具体缺什么 |
| `[红旗]` | 硬伤，直接影响结论可信度 |

## 6 大国际报告规范（方法学自检清单）

| 规范 | 适用 | 常见缺失项 |
|---|---|---|
| **PRISMA 2020** | 系统综述/Meta | PROSPERO 注册号、检索策略全文、流程图 |
| **CONSORT** | RCT | 随机序列生成、分配隐藏、盲法实施 |
| **STROBE** | 观察性研究 | 混杂控制、缺失数据处理 |
| **MOOSE** | Meta 分析（旧） | 已被 PRISMA 取代 |
| **COREQ** | 质性研究 | 研究者反身性声明 |
| **ARRIVE 2.0** | 动物实验 | 样本量计算、随机化、盲法、动物排除标准 |

**经验法则**：老论文（2019 年前）常缺 PROSPERO/ARRIVE 声明——是时代局限而非刻意隐瞒，批判时要区分。

## 红旗速查（贴墙版）

```
1. 没报告样本量计算
2. 没报告伦理批准号
3. 作者说"无局限性"
4. 效应极强但样本极小
5. 资金来源是商业公司
6. 结论"颠覆性"但只有单一实验证据
7. 综述没写检索策略（系统性存疑）
8. 图表与正文数字对不上
```

## 批判性 ≠ 抬杠

批判性阅读的产出不是"这篇论文很烂"，而是：
1. **可信度分层**：哪些结论是硬证据，哪些是暂定
2. **弱点即机会**：作者没做的实验 = 你的创新点
3. **方法学升级**：用 ARRIVE 2.0/PROSPERO 标准改进自己课题设计
